# ❤️ Heart Disease Classification

A machine learning project that uses patient clinical attributes to classify whether a patient is likely to have heart disease.

## 📌 Project Overview

The goal of this project is to explore a heart disease dataset, perform exploratory data analysis, train multiple machine learning classification models, and compare their performance.

This project was created for learning and educational purposes and is not intended for medical diagnosis.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset

The dataset contains 109 records with clinical features including:

- Age
- Sex
- Chest Pain
- Resting Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- Heart Disease

## 🔍 Exploratory Data Analysis

The project explores:

- Dataset structure
- Target distribution
- Age distribution
- Heart disease frequency
- Chest pain categories
- Relationship between age and maximum heart rate
- Feature relationships using visualizations

## 🤖 Machine Learning Models

Three classification models were tested:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Random Forest

## 📈 Model Results

| Model | Test Accuracy |
|---|---:|
| Logistic Regression | 95.45% |
| KNN | 72.73% |
| Random Forest | 100% |

Random Forest achieved the highest test-set score in this experiment.
